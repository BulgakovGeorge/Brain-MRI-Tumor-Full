# Здоровье под контролем ИИ — выявление и локализация опухолей на МРТ головного мозга

Трек «Студенты», Медицина 2050. Классы: глиома, менингиома, опухоль гипофиза, нет опухоли.
Система — вспомогательный инструмент для врача, диагноз не ставит.

## Что умеет приложение
- Определяет тип образования на МРТ (T1 с контрастом) и показывает вероятности классов и оценку надёжности.
- Выделяет область опухоли (сегментация) и отмечает участки границы, в которых модель неуверенна.
- Проверяет согласованность двух моделей (классификатор и сегментатор) и предупреждает о расхождениях.
- Считает размер области в условных единицах (1 ед. = 1/100 площади прямоугольника, ограничивающего голову; на снимок можно наложить сетку 10×10).
- Позволяет врачу исправить маску карандашом и ластиком, отредактировать проект заключения и сохранить результат (маски, текст, журнал изменений, DOCX).

> ⚠️ Исследовательский прототип. Не является медицинским изделием; результаты не являются диагнозом и должны проверяться врачом.

## Быстрый старт

Система запускается локально. Нужен Python 3.10–3.12 и около 1 ГБ свободного места. GPU не обязателен (на процессоре работает медленнее).

### 1. Скачать проект и установить библиотеки
```bash
git clone https://github.com/BulgakovGeorge/Brain-MRI-Tumor-Full.git
cd Brain-MRI-Tumor-Full
python -m pip install -r requirements.txt
```
Рекомендуется сначала создать виртуальное окружение:
`python -m venv .venv`, затем активировать его
(Windows PowerShell: `.venv\Scripts\Activate.ps1`; macOS/Linux: `source .venv/bin/activate`).
Если при запуске будет сообщение, что не найден `torch`, выполните `python -m pip install torch torchvision`.

### 2. Скачать веса моделей
Веса весят около 200 МБ, поэтому не хранятся в репозитории, а лежат в разделе
[Releases](https://github.com/BulgakovGeorge/Brain-MRI-Tumor-Full/releases).

**Способ А — одной командой** (скачает и распакует архив в нужную папку):
```bash
python download_weights.py
```

**Способ Б — вручную:**
1. Откройте [Releases](https://github.com/BulgakovGeorge/Brain-MRI-Tumor-Full/releases) и скачайте файл `weights_bundle.zip`.
2. Распакуйте его **в корень проекта** (рядом с `README.md`), чтобы получилась папка `weights/`.

После этого структура должна выглядеть так:
```
weights/
├─ classifier/convnext_tiny_base/   (model_state.pt, config.json, reference_bank.npz, prototype_config.json)
└─ seg_run/                         (seg_model.pt, seg_config.json, seg_infer.py, seg_metrics.json)
```

### 3. Запустить
```bash
python -m streamlit run app/app.py
```
Приложение откроется в браузере (обычно `http://localhost:8501`). Загрузите снимок (png/jpg) или выберите пример.

## Как пользоваться
1. Загрузите снимок: появятся вероятности классификатора, маска опухоли и проект заключения.
2. Переключатель «Какую маску показать на снимке»: маска ИИ, маска врача или без маски. Красные участки контура — неуверенная граница.
3. Галочка «Показать сетку 10×10»: 1 клетка = 1 условная единица.
4. Вкладка «Редактирование маски»: карандаш добавляет, ластик стирает; «Применить правки» сохраняет изменение.
5. Отредактируйте текст заключения и нажмите «Сохранить случай»: сохраняются снимок, маска ИИ, итоговая маска, текст до и после правок, DOCX и журнал изменений.

## Ограничения
- Анализ выполняется по одному 2D-снимку; анамнез и другие МР-последовательности не учитываются.
- Размеры указаны в условных единицах и не переводятся в миллиметры (масштаб снимков неизвестен).
- Сторона пациента (право/лево) по изображению не определяется: в тексте положение описано относительно снимка.
- Сегментатор обучен на наборе BRISC 2025; на снимках из других источников качество может отличаться.
- Класс «нет опухоли» в обучающих данных визуально отличается от снимков с опухолями, поэтому доля ложных срабатываний на «норме» может быть занижена.

## Данные
Данные в репозиторий не включены. Сегментатор обучался на открытом наборе BRISC 2025
(Kaggle: `briscdataset/brisc2025`); условия использования смотрите на странице набора.
В папке `examples/` лежат примеры снимков для демонстрации.
